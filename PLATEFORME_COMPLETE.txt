🎉 PLATEFORME ENERGIEPLUS - RÉCAPITULATIF COMPLET
===================================================

📊 VUE D'ENSEMBLE
-----------------
Plateforme web complète pour la vente et simulation de solutions énergétiques
en Belgique (Particuliers & Sociétés)

🎯 3 ACTEURS PRINCIPAUX
------------------------

1️⃣ PARTICULIERS
   - Accès au catalogue de produits
   - Formulaire multi-étapes (6 étapes)
   - Simulation d'économies avec score
   - Prise de rendez-vous
   - Chatbot IA assistance

2️⃣ SOCIÉTÉS
   - Même fonctionnalités que particuliers
   - Formulaire adapté (infos entreprise)
   - Calcul primes spécifiques

3️⃣ ADMINISTRATEURS
   - Espace admin sécurisé
   - Gestion formulaires/RDV/produits
   - Dashboard statistiques
   - Export données CRM

🌍 3 RÉGIONS BELGES
-------------------
- Wallonie (primes régionales)
- Bruxelles (primes régionales)
- Flandre (primes régionales)

📦 6 PRODUITS ÉNERGÉTIQUES
--------------------------
1. Panneaux solaires photovoltaïques (3-12 kWc)
2. Batteries domestiques (5-15 kWh)
3. Pompes à chaleur Air-Eau
4. Pompes à chaleur Air-Air
5. Pompes à chaleur Géothermiques
6. Bornes de recharge véhicules électriques

🗺️ ARCHITECTURE DU SITE
========================

📄 PAGES PUBLIQUES (avec Navbar + Footer + Chatbot)
----------------------------------------------------

1. PAGE D'ACCUEIL (/)
   - Hero section avec CTA
   - Présentation solutions
   - 2 boutons principaux:
     • "Commencer la simulation" → /formulaire
     • "Voir notre catalogue" → /catalogue
   - Statistiques
   - Témoignages

2. CATALOGUE (/catalogue)
   - Liste des 6 produits
   - Filtres: type, prix, région
   - Cartes produits interactives
   - Bouton "En savoir plus" → /produit/:id

3. DÉTAIL PRODUIT (/produit/:id)
   - Informations complètes
   - Caractéristiques techniques
   - Primes par région
   - Bouton "Commander" → /formulaire/:productId

4. FORMULAIRE (/formulaire ou /formulaire/:productId)
   📝 6 ÉTAPES:
   
   Étape 1: Type de profil
   - Particulier / Société
   
   Étape 2: Informations personnelles
   - Nom, prénom, email, téléphone
   - (Si Société: nom entreprise, TVA, secteur)
   
   Étape 3: Localisation
   - Région: Wallonie/Bruxelles/Flandre
   - Adresse, code postal, ville
   
   Étape 4: Situation énergétique
   - Type logement (maison/appartement)
   - Année construction
   - Surface habitable
   - Consommation électrique annuelle
   - Consommation gaz
   - Type chauffage actuel
   
   Étape 5: Objectifs
   - Réduire facture
   - Autonomie énergétique
   - Environnement
   - Confort thermique
   
   Étape 6: Besoins énergétiques (si pas de produit pré-sélectionné)
   - Panneaux solaires
   - Batterie domestique
   - Pompe à chaleur
   - Solution complète
   
   → Validation et envoi
   → Redirection vers /simulation/:id

5. SIMULATION (/simulation/:simulationId)
   - Récapitulatif données client
   - Produit recommandé (intelligent)
   - Calcul des économies:
     • Économies annuelles
     • Économies 20 ans
     • Retour sur investissement
     • Primes régionales automatiques
   - Score environnemental (0-100)
   - Graphique évolution
   - Bouton "Prendre rendez-vous" → /rendez-vous

6. PRISE DE RENDEZ-VOUS (/rendez-vous)
   - Calendrier interactif
   - Sélection date/heure
   - Type de rendez-vous:
     • Visite technique
     • Appel téléphonique
     • Visio-conférence
   - Confirmation par email

🔐 PAGES ADMIN (sans Navbar/Footer publics)
--------------------------------------------

7. LOGIN ADMIN (/admin/login)
   - Formulaire authentification
   - Identifiants démo: admin/admin123
   - Stockage token localStorage
   - Redirection vers dashboard

8. DASHBOARD ADMIN (/admin/dashboard)
   
   📊 ONGLET 1: VUE D'ENSEMBLE
   - 4 cartes statistiques:
     • Total formulaires
     • Formulaires en attente
     • RDV programmés
     • RDV aujourd'hui
   - Tableau derniers formulaires
   - Liste prochains rendez-vous
   
   📝 ONGLET 2: FORMULAIRES
   - Filtres: recherche, statut, région
   - Tableau complet avec:
     • ID, Client, Profil, Région
     • Besoin, Email, Date, Statut
     • Actions: Voir/Modifier/Supprimer
   
   📅 ONGLET 3: RENDEZ-VOUS
   - Vue calendrier
   - Cartes de RDV avec:
     • Client, Date, Heure
     • Type, Statut
     • Actions: Annuler/Confirmer
   
   📦 ONGLET 4: PRODUITS
   - Bouton ajouter produit
   - Gestion catalogue (à implémenter)
   
   📈 ONGLET 5: STATISTIQUES
   - Graphiques données
   - Formulaires par région
   - Évolution demandes
   
   Fonctionnalités communes:
   - Export données Excel/CSV
   - Déconnexion
   - Retour au site
